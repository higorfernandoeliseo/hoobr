    Adicionar meu projeto

    Feito por devs, para devs. se você é brasileiro e quer divulgar seu projeto aqui contribua adicionando seu projeto.

    Você pode fazer o fork pelo GitHub ou pelo Git clone na linha de comando usando Prompt de comando ou Powershell.

    O fluxo padrão para qualquer desenvolvedor que queira listar um projeto será:

    1. O colaborador faz um fork do repositório hoobr.

    2. Faça um clone do repositório 'git clone https://github.com/higorfernandoeliseo/hoobr.git'

    3. Abra no seu editor favorito o arquivo 'projects.json' no diretório 'assets/db'.

    4. Adicione seu projeto criando um novo objeto ao array dentro do arquivo "projects.json"

    5. Adicione os arquivos com 'git add .' e comite as alterações com 'git commit -m "Descreva o que alterou em poucas palavras" '.

    6. Dê um 'git push origin master'

    7. Acesse o repositório no GitHub. Clique no botão "Compare & pull request" que aparecerá.

    8. preencha o título e a descrição sobre o projeto a ser adicionado, e clique em "Create pull request".

    Aguarde a adição ser aprovada o projeto será adicionado na plataforma.
